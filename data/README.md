# Data

- `raw/`: dataset sumber yang belum diproses.
- `processed/`: hasil preprocessing untuk training atau inference.
- `samples/`: contoh kecil yang boleh masuk Git untuk development.

Isi `raw` dan `processed` diabaikan Git. Catat sumber, waktu pengambilan, satuan, dan lisensi ketika menambahkan dataset nyata. Semua data `samples/alerts.json` bersifat sintetis.
