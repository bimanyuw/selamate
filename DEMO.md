# Demo admin dan driver

1. Klik `Jalankan-Selamate-HP.cmd` di laptop. Tailscale di laptop dan HP harus aktif. Tidak perlu Jupyter.
2. Buka `.tmp/demo-accounts.json` untuk email dan password dua akun. Akun Admin: `admin@selamate.demo`; akun Driver: `driver@selamate.demo`. Untuk menyiapkan ulang secara idempotent: `npm.cmd run demo:accounts`.
3. Di laptop, buka `http://localhost:5173` dan login akun Admin. Di HP, buka alamat HTTPS Tailscale yang ditampilkan launcher dan login akun Driver. Jika mencoba dua akun pada satu perangkat, gunakan browser/profile terpisah agar cookie sesi tidak saling mengganti.
4. Driver menekan **Aktifkan kamera** dan memberikan izin kamera/GPS. Tampilan driver tetap kamera di kiri dan pesan admin di kanan.
5. Admin melihat driver pada **Pilih driver untuk dipantau**. Driver pertama dengan kamera aktif dipantau otomatis. Jika ada beberapa sesi, klik **Pantau** pada driver yang diinginkan.
6. Panel **LIVE DRIVER CAMERA** menampilkan frame kamera HP yang diperbarui berkala; snapshot dashboard diperbarui setiap detik. Panel **Kondisi driver** menampilkan **Terjaga**, **Mengantuk**, **Lelah**, atau **Data belum cukup**. Hasil mulai digunakan setelah minimal lima detik pengamatan dan cakupan deteksi yang memadai. Arahkan kamera depan ke wajah, gunakan pencahayaan cukup, dan pastikan mata terlihat. Wajah/mata tidak terdeteksi tidak dianggap terjaga.
7. Admin dapat menulis pesan pada **Notifikasi untuk driver**, lalu memilih **Kirim notifikasi** untuk teks atau **Bunyikan ringtone** untuk alarm. Ringtone juga bisa dikirim tanpa mengetik pesan. Driver menggeser kontrol **Geser aktifkan suara** jika suara belum aktif, atau **Geser untuk tes suara** untuk mencoba alarm dan getar. Pola getar dikirim pada browser yang mendukung Vibration API; browser/perangkat dapat menolaknya. Admin melihat status kesiapan suara dan konfirmasi ketika ringtone dimulai atau dihentikan. Driver menekan **Hentikan alarm** untuk menghentikan suara dan getar; alarm juga berhenti otomatis setelah 30 detik. Biarkan halaman driver terbuka dan layar menyala selama demo; ringtone ini merupakan suara dari halaman web, bukan panggilan telepon yang dapat membangunkan HP terkunci.
8. Driver menekan **Hentikan kamera** untuk mengakhiri sesi. Restart backend juga menghapus sesi, tetapi akun tetap tersimpan di database.

Model asli dari Downloads disalin ke `models/eye_detector.pt`; kelasnya `closed` dan `open`. Inference berjalan langsung di backend. Frame kamera tidak disimpan ke disk; hanya frame terakhir per sesi disimpan di memori dan dapat dibaca oleh pemilik atau Admin. Preview berupa gambar berurutan, bukan WebRTC video 30 FPS; kelancaran tergantung jaringan dan waktu inference CPU. Kamera dan status kantuk memiliki usia data terpisah agar gambar baru tidak membuat hasil deteksi lama tampak terbaru.

Jika dependensi belum terpasang: `.venv\Scripts\python.exe -m pip install -e "./backend[dev]" -e "./ai[vision]"`. Password demo di `.tmp` dan file model diabaikan Git.
